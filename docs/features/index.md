# GitSpectra Features

**Local-First Repo Intelligence. See the full spectrum of your Git.**

GitSpectra transforms how you work with Git by detecting conflicts *before* they happen—all without leaving your editor or sending data to any cloud service.

---

## Core Features

<div class="feature-grid">

### [🎯 Real-Time Conflict Detection](./conflict-detection.md)
See conflicts as you type—not when you try to merge. Know instantly when a teammate has changed lines you're working on.

### [📊 Conflict Radar Panel](./conflict-radar.md)
A dedicated sidebar showing all detected conflicts across your workspace, organized by severity and file.

### [📰 Activity Feed](./activity-feed.md)
Stay informed about what your team is doing. See recent commits, who's touching which files, and identify hot spots of activity.

### [✨ Editor Decorations](./editor-decorations.md)
Inline gutter icons and line highlighting that show exactly which lines have potential conflicts.

### [💬 Rich Hover Tooltips](./hover-tooltips.md)
Hover over any conflict indicator to see who made the change, when, and on which branch—with quick actions.

### [🔍 Multi-File Diff View](./multi-diff-view.md)
View all changes from a commit in a single, scrollable PR-like diff view using VS Code's native capabilities.

</div>
