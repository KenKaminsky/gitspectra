## Screenshot Guidelines

### Dimensions
- **Full panels**: 800-1200px wide
- **Closeups**: 400-600px wide
- **Diagrams**: As needed

### Format
- PNG for screenshots
- SVG for diagrams (if possible)

### Style
- Use a consistent VS Code theme (suggest: dark theme)
- Clean editor with relevant code visible
- Highlight key UI elements if helpful
- Remove or blur any sensitive information

### Demo Mode
Use GitSpectra's Demo Mode to create consistent, repeatable screenshots:
```
GitSpectra: Demo - Start Scenario → Full Overview
```
